1. Математическое обоснование метода¶

1.1. Метод обратной функции (Inverse Transform Sampling)¶

Фундаментальная теорема моделирования случайных величин гласит:

Если случайная величина $U$ имеет стандартное непрерывное равномерное распределение на отрезке $[0, 1]$ ($U \sim U[0, 1]$), а $F(x)$ — непрерывная строго монотонная функция распределения, то случайная величина $$X = F^{-1}(U)$$ имеет функцию распределения $F(x)$.

Действительно: $$\mathbb{P}(X \le x) = \mathbb{P}(F^{-1}(U) \le x) = \mathbb{P}(U \le F(x)) = F(x)$$

1.2. Метод обратной функции распределения с интерполяцией для cal_pka_basic¶

Величина cal_pka_basic ($pK_a$) — непрерывная физико-химическая величина. Она может принимать любые дробные значения на числовой прямой, а не только фиксированные целые числа.

Обычная эмпирическая функция распределения (ЭФР) строится по точкам выборки в виде ступенчатой «лесенки»: $$F_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbf{1}_{\{x_i \le x\}}$$ Каждое наблюдение увеличивает накопленную вероятность на ступеньку высотой $1/n$.

Если взять обратную функцию прямо к ступенчатой ЭФР: $$F_n^{-1}(u) = x_{(\lceil n \cdot u \rceil)}$$ то генератор будет просто случайно выбирать уже существующие числа из исходной таблицы. В результате одни и те же значения будут постоянно повторяться, а новые промежуточные числа появиться не смогут. Для дискретных величин (например, количества атомов или связей) это допустимо, но для непрерывной величины $pK_a$ постоянные повторы одних и тех же точек некорректны.

Чтобы генератор мог создавать новые непрерывные значения, ступеньки соединяют прямыми линиями — этот метод называется обратной функцией распределения с интерполяцией.

Как устроен алгоритм:

  1. Исходные значения сортируются по возрастанию: $$x_{(1)} \le x_{(2)} \le \dots \le x_{(n)}$$
  2. Каждому значению $x_{(i)}$ ставится в соответствие накопленная вероятность на равномерной сетке от $0$ до $1$: $$p_i = \frac{i - 1}{n - 1}, \quad i = 1, \dots, n \quad (p_1 = 0, \; p_n = 1)$$
  3. Чтобы сгенерировать случайное число, берем случайную величину $u$, равномерно распределенную на отрезке $[0, 1]$.
  4. Находим два соседних значения $p_i$ и $p_{i+1}$, между которыми оказалось число $u$ ($p_i \le u \le p_{i+1}$).
  5. Значение $x$ вычисляется с помощью обычной линейной интерполяции (пропорционально расстоянию от $p_i$ до $p_{i+1}$): $$x = x_{(i)} + \frac{u - p_i}{p_{i+1} - p_i} \cdot \left( x_{(i+1)} - x_{(i)} \right)$$

Преимущества метода:

  1. Непрерывность: генератор создает новые вещественные значения между точками выборки в диапазоне $[x_{(1)}, x_{(n)}]$, исключая искусственные повторы одинаковых чисел;
  2. Точность: сгенерированная выборка строго сохраняет форму, пики и разброс исходного распределения;
  3. Эффективность: сортировка данных выполняется один раз в конструкторе при создании объекта, а расчет новых чисел происходит мгновенно с помощью векторных операций NumPy (np.interp).

2. Программная реализация генератора¶

Класс EcdfContinuousGenerator наследуется от базового класса BaseGenerator:

  • Конструктор __init__(data): принимает массив данных, отсекает возможные пропуски NaN, сортирует вариационный ряд и формирует интерполяционную сетку вероятностей $p \in [0, 1]$.
  • Метод generate(n, random_state=None): принимает объем выборки $n$, валидирует входные параметры, инициализирует генератор np.random.default_rng(random_state), генерирует $U \sim U(0, 1)$ и преобразует его через интерполятор квантилей в одномерный массив NumPy.

5.3. Дополнительно: Проверка независимости сгенерированных значений¶

Случайные величины в выборке должны быть независимы друг от друга, то есть предыдущее сгенерированное значение не должно определять следующее. Для проверки этого смотрим на два показателя:

  1. Автокорреляционная функция (АКФ): коэффициенты корреляции для сдвигов (лагов) от 1 до 25 должны находиться внутри 95% доверительного интервала Бартлетта ($\pm 1.96 / \sqrt{n}$).
  2. Критерий серий Вальда — Вольфовица (Runs test): проверяет, случайно ли чередуются элементы выборки выше и ниже медианы.

  1. Как устроен генератор: Вся подготовительная работа (фильтрация пропусков, сортировка и расчет сетки) выполняется один раз при создании объекта генератора. После этого вызов метода generate(n, random_state) работает очень быстро и дает полностью воспроизводимые выборки при фиксации seed.

  2. Зачем понадобилась интерполяция: Если бы мы использовали прямое обращение обычной ступенчатой ЭФР, генератор бы просто случайно извлекал уже имеющиеся в датасете числа, из-за чего точки постоянно повторялись бы. Линейная интерполяция между соседними точками выборки позволила избавиться от повторов и моделировать действительно непрерывные значения, аккуратно сохраняя форму распределения.
